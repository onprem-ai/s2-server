# Hardware: vendor documents per component

One folder per component of the [BOM](../01-bom.md), named by its role (`psu/`, not the
model), so links stay valid when a model changes. Each holds the vendor's manuals,
datasheets and product images, with a `README.md` that names the source of every file.
Download from the vendor's own site; note the date and the URL.
