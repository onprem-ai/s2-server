# Rack rails (optional): SilverStone RMS05-22

Ball-bearing slide rail kit for mounting the RM4A chassis in a rack. Optional: only
for a rack, not for a machine that stands on a shelf.
[Product page](https://www.silverstonetek.com/en/product/info/server-nas/RMS05-22/).
Downloaded 2026-10-24 from SilverStone.

**The RM4A takes no standard rails.** It needs this SilverStone kit, which is also
the one SilverStone lists for the RM4A
([RMS rail compatibility](https://www.silverstonetek.com/en/page/RMS-comparison)).
Order it with the chassis when the machine goes into a rack.

Installation, in short (details in the manual): take the inner member off each rail
and fix it to the chassis; click the outer members into the rack; pull the middle
members out until they lock, with the ball-bearing retainer at the front; slide the
chassis in, press the release tab at the stop, push it home.
