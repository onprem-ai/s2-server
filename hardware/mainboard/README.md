| Connector | What | S2 |
|---|---|---|
| ATX_PWR | 24-pin main power | Yes |
| CPU_12V_1, CPU_12V_2 | Two 8-pin CPU power connectors. The manual (section 1.2, power connectors): connect the 8-pin plug, or both | Both, one PSU cable each |
| CPU_12V_LED | Lights up while an 8-pin CPU power plug is missing | Off when both are in |
